# Aromina Farma S.R.L. — proiect școlar Dumitru Andreea Teodora

**Operator IT:** Dumitru Andreea Teodora  
**Website public:** https://enzosystems-admin.github.io/aromins-farma-demo/  
**Temă:** concept de magazin online cu produse pentru bebeluși și părinți.

Acesta este un website **demonstrativ**, în limba română, pentru un magazin de articole destinate bebelușilor, inspirat de structura funcțională a magazinelor de tip Bebe Tei, însă cu identitate vizuală și conținut propriu.

## Cum îl deschizi

1. Extrage arhiva ZIP pe calculator.
2. Dă dublu click pe `index.html` pentru a-l deschide în Chrome, Edge sau Firefox.
3. Nu trebuie instalat nimic și nu este necesar internetul.

## Ce funcționează

- Prezentare, categorii de produse, secțiune „Despre” și întrebări frecvente.
- Căutare produse și filtrare pe categorii.
- Sortare după preț sau nume.
- Pagini de detalii în fereastră popup.
- Adăugare/eliminare favorite.
- Coș de cumpărături demonstrativ, actualizare cantități și total.
- Păstrarea coșului și favoritelor în browser (localStorage).
- Design adaptat la telefon, tabletă și desktop.

## Cum modifici

- `index.html` — textele secțiunilor și structura site-ului.
- `styles.css` — culori, fonturi, dimensiuni, layout.
- `app.js` — lista produselor demonstrative, prețurile și interacțiunile.
- Nu există bază de date, autentificare, plăți, stocuri reale sau comenzi reale.

## Notă importantă

Este un proiect educațional. Numele produselor, ambalajele, prețurile și informațiile de produs sunt fictive. Nu reprezintă o farmacie autorizată și nu trebuie utilizat pentru comercializare fără integrarea cerințelor legale, de protecția datelor și de securitate corespunzătoare.
